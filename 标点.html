Punto (.) 句号
El punto se utiliza para indicar el final de un sentido completo. Existen tres tipos: punto y seguido (dentro del párrafo), punto y aparte (cambio de párrafo) y punto final (conclusión del texto). También es fundamental en las abreviaturas. 句号用于表示完整意思的结束。分为三种：句中点（用于句内）、段落点（用于分段）和终结点（用于全篇结束）。在缩写词中也必不可少。

Ejemplos / 例子

El sol sale cada mañana. Es un nuevo día. 太阳每天升起。这是新的一天。
El Sr. García llegó tarde. García 先生迟到了。
Estudiamos para el examen. Fin. 我们为考试学习。结束。
Coma (,) 逗号
Representa una pausa breve. Se usa para separar elementos de una lista, para aislar el nombre de la persona a la que llamamos (vocativo) o para añadir explicaciones (incisos). Nunca debe separar el sujeto del verbo. 表示短暂停顿。用于分隔列表项，隔离呼唤的人名（呼语），或添加说明（插入语）。绝不应将主语和动词分隔开。

Ejemplos / 例子

Compré manzanas, peras y limones. 我买了苹果、梨和柠檬。
María, escucha con atención. 玛丽亚，认真听。
Valencia, la ciudad de las flores, es hermosa. 瓦伦西亚，这座鲜花之城，非常美丽。
Dos puntos (:) 冒号
Se usan para detener el discurso y llamar la atención sobre lo que sigue. Es común en los encabezamientos de cartas, antes de una cita textual o para iniciar una enumeración. 用于暂停叙述并引起对后续内容的注意。常见于信件开头、直接引用原话前或开始列举前。

Ejemplos / 例子

Estimada directora: 尊敬的女校长：
Dijo el profesor: "Saquen sus libros". 老师说：“拿出你们的书。”
Solo necesito tres cosas: paz, tiempo y café. 我只需要三样东西：和平、时间和咖啡。
Interrogación y Exclamación (¿? ¡!) 问号与感叹号
En español son signos dobles: obligatoriamente deben ir al principio y al final del enunciado. Los de interrogación marcan una pregunta y los de exclamación expresan sentimientos fuertes o mandatos. 在西班牙语中它们是双符号：必须出现在句首和句尾。问号标记提问，感叹号表达强烈情感或指令。

Ejemplos / 例子

¿Cuántos años tienes? 你几岁了？
¡Qué alegría verte de nuevo! 再次见到你真高兴！
¿Adónde vas? ¡Vuelve aquí! 你去哪？快回来！
Raya (—) 破折号 / 对话符
Es más larga que el guion. Se utiliza principalmente para introducir las intervenciones de los personajes en un diálogo o para encerrar aclaraciones que interrumpen el discurso principal. 它比连字符更长。主要用于在对话中引入角色的发言，或括起打断主叙述的说明文字。

Ejemplos / 例子

—Hola, ¿cómo estás? —Muy bien, gracias. “你好吗？”“很好，谢谢。”
La casa —construida en 1920— se derrumbó. 那栋房子——建于1920年——倒塌了。
—No quiero ir —susurró él. “我不想去，”他低声说。
Diéresis (¨) 分音符
Es un signo que se coloca sobre la "u" para indicar que esta debe pronunciarse en las combinaciones "gue" y "gui". Sin ella, la "u" sería muda. 这是放在 "u" 上的符号，表示在 "gue" 和 "gui" 组合中 "u" 必须发音。如果没有它，"u" 将不发音。

Ejemplos / 例子

El pingüino vive en el hielo. 企鹅生活在冰上。
Siento mucha vergüenza. 我感到很羞愧。
La cigüeña vuela alto. 鹳鸟飞得很高。
Comillas (« ») 书名号 / 引号
En español se prefieren las comillas angulares o latinas (« »). Se usan para citar palabras de otros, para indicar que una palabra es irónica o para mencionar títulos de artículos o poemas. 在西班牙语中首选书名号（角引号）。用于引用他人原话、表示讽刺意味，或提及文章和诗歌的标题。

Ejemplos / 例子

Leí el poema «Caminante no hay camino». 我读了《行人啊，本没有路》这首诗。
Ella es muy «lista» (en sentido irónico). 她可真是“聪明”（反话）。
Dice el cartel: «Prohibido fumar». 牌子上写着：“禁止吸烟”。
