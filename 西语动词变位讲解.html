西语动词变位精讲课堂 · 全时态规律与场景图解

第一讲：西语动词全景地图——三大语式与变位逻辑
LECCIÓN 1 · PANORAMA GENERAL

为什么西语动词要变位？三大语式怎么分？

💡 核心概念：西班牙语通过改变动词词尾（有时也改变词干），一次性把“是谁做的（6个人称）”和“什么时候/什么态度做的（时态与语式）”合并在一个词里，所以日常说话经常省略主语代词（如直接说 Hablo español）。

1. 陈述式 (Modo Indicativo)

关键词：客观事实
用来描述真实发生过、正在发生、将要发生或客观存在的事实，包含 5个简单时态 + 5个复合时态。

2. 命令式 (Modo Imperativo)

关键词：指令、请求与禁止
直接对听话人发出命令、建议或禁止，分为肯定命令式和否定命令式（注意没有第一人称单数 yo）。

3. 虚拟式 (Modo Subjuntivo)

关键词：主观情感、愿望与假设
表达“希望、怀疑、开心、建议、目的”等主观态度，通常躲在 que 引导的从句里。

📌 认识动词原形的三大变位组（词根 + 词尾）

所有西班牙语动词原形（Infinitivo）都以 -ar（第一变位）、-er（第二变位）、-ir（第三变位）结尾。去掉这两个字母剩下的部分叫词根（Raíz）：

变位分组 原形 (Infinitivo) 词根 (Raíz) 词尾 (Terminación) 中文词义
第一变位 (-ar) hablar habl- -ar 说话；讲
第二变位 (-er) comer com- -er 吃
第三变位 (-ir) vivir viv- -ir 居住；生活

第二讲：陈述式简单时态（现在、简单过去、未完成过去、将来与条件）
LECCIÓN 2 · INDICATIVO SIMPLE

陈述式五大简单时态规则与核心对比

2.1 陈述式现在时 (Presente de Indicativo)
常见信号词： ahora (现在) siempre (总是) todos los días (每天) a veces (有时候)
人称 -ar (hablar 说话) -er (comer 吃) -ir (vivir 居住)

2.2 难点突破：简单过去时 (Indefinido) vs. 未完成过去时 (Imperfecto)

🎬 简单过去时 (Pretérito Indefinido)

用法：过去某个明确时间点已经做完的动作（像电影里的具体事件推进）。

ayer (昨天) anoche (昨晚) el año pasado (去年)
人称-ar (hablar)-er / -ir (comer / vivir)
yohablécom / viví
túhablastecom / viviste
él / ella / Ud.hablócom / vivió
nosotros / ashablamoscom / vivimos
vosotros / ashablasteiscom / vivisteis
ellos / Uds.hablaroncom / vivieron

🖼️ 未完成过去时 (Pretérito Imperfecto)

用法：过去的习惯性动作、年龄时间、天气环境或背景描写（全西语仅 ser, ir, ver 三个不规则！）。

cuando era niño (小时候) siempre (过去总是) mientras (正当…时)
人称-ar (hablar)-er / -ir (comer / vivir)
yohablabacom / vivía
túhablabascom / vivías
él / ella / Ud.hablabacom / vivía
nosotros / ashablábamoscom / vivíamos
vosotros / ashablabaiscom / vivíais
ellos / Uds.hablabancom / vivían
Ayer fui al parque, pero cuando era pequeño iba todos los días. 昨天我去了一次公园（简单过去时：单次完成），但小时候我每天都去（未完成过去时：过去习惯）。
2.3 将来未完成时 (Futuro Simple) & 简单条件式 (Condicional Simple)
🌟 超省力记忆法：这两个时态不需要去掉词尾！无论动词以 -ar、-er 还是 -ir 结尾，都直接把整套词尾加在动词原形（Infinitivo）后面即可。
人称 将来未完成时 (原形 + 词尾) 简单条件式 (原形 + 词尾)
yohablaréhablaría
túhablaráshablarías
él / ella / Ud.hablaráhablaría
nosotros / ashablaremoshablaríamos
vosotros / ashablaréishablaríais
ellos / ellas / Uds.hablaránhablarían

共用不规则词干（12个常见词）：tener → tendr-，poner → pondr-，salir → saldr-，venir → vendr-，poder → podr-，saber → sabr-，querer → querr-，decir → dir-，hacer → har-。

❓ 随堂微测验 / Comprueba lo aprendido
1. Mientras yo _______ (estudiar), mi hermano _______ (entrar) en la habitación. 当我正在学习的时候，我弟弟走进了房间。（填入正确过去时态）
👉 Respuesta
estudiaba (未完成过去时，表示背景持续动作) / entró (简单过去时，表示突然插入并完成的动作)。

第三讲：陈述式复合时态（万能公式：haber + 过去分词）
LECCIÓN 3 · INDICATIVO COMPUESTO

学会一个公式，打通陈述式全部 5 个复合时态

助动词 haber（按人称变位） + 实义动词的过去分词（-ado / -ido，词尾永不变！）
复合时态名称 助动词 haber 六人称变位 搭配过去分词示例 核心时间含义
现在完成时
Pretérito Perfecto		 he, has, ha, hemos, habéis, han he hablado / comido 今天、本周等未结束时间段内已完成的动作（hoy, esta semana）
过去完成时
Pluscuamperfecto		 había, habías, había, habíamos, habíais, habían había hablado / comido “过去的过去”（在过去某件事之前就已经发生了）
先过去时
Pretérito Anterior		 hube, hubiste, hubo, hubimos, hubisteis, hubieron hube hablado / comido 紧接在另一过去动作之前（现代口语极少用，多见于文学作品）
将来完成时
Futuro Perfecto		 habré, habrás, habrá, habremos, habréis, habrán habré hablado / comido 到将来某个时间点之前将会已经做完的事
复合条件式
Condicional Perfecto		 habría, habrías, habría, habríamos, habríais, habrían habría hablado / comido 过去本可以/本应该做某事（与虚拟式过去完成时连用）
🔥 必背十大不规则过去分词（复合时态高频考点）：
abrir → abierto（打开） · decir → dicho（说） · escribir → escrito（写） · hacer → hecho（做） · morir → muerto（死） · poner → puesto（放） · romper → roto（打破） · ver → visto（看） · volver → vuelto（回来） · resolver → resuelto（解决）。
Hoy hemos hecho todos los deberes antes de cenar. 今天晚饭前我们已经把所有作业都做完了。（hoy 搭配现在完成时 + 不规则分词 hecho）

第四讲：命令式（肯定命令式 vs. 否定命令式与代词位置）
LECCIÓN 4 · MODO IMPERATIVO

命令式变位规则与代词“前否定、后肯定”口诀

人称 肯定命令式规则 示例 (hablar / comer / vivir) 否定命令式规则（全部借用虚拟式现在时）
tú (你) 陈述式现在时第三人称单数
8个不规则：ten, ven, pon, sal, haz, di, ve, sé		 habla / come / vive no hables / no comas / no vivas
usted (您) 借用虚拟式现在时第三人称单数 hable / coma / viva no hable / no coma / no viva
nosotros / as 借用虚拟式现在时第一人称复数 hablemos / comamos / vivamos no hablemos / no comamos / no vivamos
vosotros / as 原形去掉 -r 改为 -d hablad / comed / vivid no habléis / no comáis / no viváis
ustedes (诸位) 借用虚拟式现在时第三人称复数 hablen / coman / vivan no hablen / no coman / no vivan
⚡ 黄金口诀：肯定后置连写（常需补重音符号），否定前置分开写！
• 自复动词 levantarse（起床）：肯定命令式 ¡Levántate!（去掉 -os 前的 -d：¡Levantaos!） vs. 否定命令式 ¡No te levantes!
• 带宾格/与格代词：肯定命令式 ¡Dímelo!（告诉我吧！） vs. 否定命令式 ¡No me lo digas!（别告诉我！）

第五讲：虚拟式（Presente, Imperfecto, 复合虚拟式与高频触发器）
LECCIÓN 5 · MODO SUBJUNTIVO

虚拟式变位“三步转换法”与常见触发句型

5.1 虚拟式现在时 (Presente de Subjuntivo) —— 元音互换法
🔑 变位三步走：
① 先写出陈述式现在时 yo 的形式（如 hablo, como, tengo, conozco）；
② 去掉词尾 -o 得到专属词根（habl-, com-, teng-, conozc-）；
③ 交换元音词尾：-ar 动词全部用 -e 系列，-er / -ir 动词全部用 -a 系列！
人称 -ar 动词 (用 -e 词尾) -er / -ir 动词 (用 -a 词尾) 不规则词根示例 (tener → teng-)
yohablecom / vivatenga
túhablescom / vivastengas
él / ella / Ud.hablecom / vivatenga
nosotros / ashablemoscom / vivamostengamos
vosotros / ashabléiscom / viváistengáis
ellos / Uds.hablencom / vivantengan

六大完全不规则词（首字母口诀 DISHES）：Dar (dé) · Ir (vaya) · Saber (sepa) · Haber (haya) · Estar (esté) · Ser (sea)。

5.2 虚拟式未完成过去时 & 复合虚拟式

虚拟式未完成过去时 (Imperfecto Subj.)

零例外万能规律：找到简单过去时 ellos（如 hablaron, tuvieron, dijeron），去掉 -ron，加上：
-ra, -ras, -ra, -ramos, -rais, -ran（nosotros 倒数第三个音节加重音符号，如 habláramos, tuviéramos）。

虚拟式复合时态 (Perfecto / Pluscuamperf.)

• 现在完成虚拟式：haya / hayas / haya... + 过去分词（如 Espero que hayas llegado bien. 希望你已经平安到了。）
• 过去完成虚拟式：hubiera / hubieras... + 过去分词（常用于与过去事实相反的假设：Si hubiera estudiado...）

5.3 看到这些“触发器”，从句立刻用虚拟式！
querer que (想要…) esperar que (希望…) ojalá (que) (但愿…) es importante / necesario que (很重要/有必要…) me alegra que (令我开心的是…) para que (为了…) antes de que (在…之前) cuando + 将来未发生动作
Quiero que practiques los verbos todos los días. 我希望你每天都练习动词变位。（主句表达主观愿望 quiero que，从句 practicar 用虚拟式现在时）

第六讲：不规则动词“家族记忆法”（互动靴子动词图解）
LECCIÓN 6 · VERBOS IRREGULARES

把零散的不规则动词归类成三大“家族”

6.1 靴子动词 (Verbos Bota) —— 词干元音变化互动图

在陈述式现在时（以及虚拟式现在时）中，很多动词的词干元音会在 yo, tú, él/ella, ellos/ellas 四个重读音节人称里分裂变化，连起来刚好像一只靴子，而靴子外面的 nosotros 和 vosotros 保持原形不变！点击下方按钮切换观察：

6.2 第一人称单数 (yo) 特殊变形家族

-go 结尾家族

tener → tengo · poner → pongo
salir → salgo · venir → vengo
hacer → hago · decir → digo
oír → oigo · traer → traigo

-zco 结尾家族（-acer / -ecer / -ocer / -ucir）

conocer → conozco（认识）
parecer → parezco（看起来）
conducir → conduzco（驾驶）
traducir → traduzco（翻译）

✍️ 正字法“保音微调”（为了读音不变而改字母）：
以 -car、-gar、-zar 结尾的动词，遇到 e 开头词尾时（如简单过去时 yo 和虚拟式现在时），需要微调拼写：
• -car → -qué：buscar → busqué（为了保持 /k/ 音，否则 ce 会读成 /θ/）
• -gar → -gué：jugar → jugué（为了保持 /g/ 音，否则 ge 会读成 /x/）
• -zar → -cé：empezar → empecé（西语拼写习惯 z 在 e/i 前改写为 c）
❓ 随堂微测验 / Comprueba lo aprendido
1. 为什么 nosotros podemos（我们能）不变成 *puedemos，而 ellos 变成 pueden？
👉 Respuesta
因为 podemos 的重音落在词尾 -de- 上，词干 po- 不是重读音节；而 pueden 的重音正好落在词干元音上，处于“靴子”区域内，所以 o 裂变为 ue。
