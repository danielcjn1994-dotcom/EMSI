Jerarquía de las Operaciones (Orden de cálculo) 运算顺序：先乘除，后加减；如果有括号，先算括号里面的。
Ejemplo: 3 + 4 × 2 = 3 + 8 = 11
(No es 7 × 2 = 14)
Uso de Paréntesis, Corchetes y Llaves 括号的使用顺序：先算小括号，再算中括号，最后算大括号。
  • ( ) Paréntesis (小括号) - Prioridad 1
  • [ ] Corchetes (中括号) - Prioridad 2
  • { } Llaves (大括号) - Prioridad 3
10 × { 5 + [ 8 - ( 2 + 3 ) ] }
= 10 × { 5 + [ 8 - 5 ] }    ← 先算 ( )
= 10 × { 5 + 3 }           ← 再算 [ ]
= 10 × 8 = 80              ← 最后算 { }
Propiedad Conmutativa 交换律：交换两个数的位置，结果不变。适用于加法和乘法。
Suma: a + b = b + a
Mult: a × b = b × a
Propiedad Asociativa 结合律：三个数相加或相乘，先把前两个数相加/乘，或者先把后两个数相加/乘，结果不变。
Suma: (a + b) + c = a + (b + c)
Mult: (a × b) × c = a × (b × c)
Propiedad Distributiva 分配律：一个数乘两个数的和，等于这个数分别乘这两个数，再相加。
a × (b + c) = a × b + a × c
Ejemplo: 2 × (3 + 4) = 2×3 + 2×4 = 6 + 8 = 14

A. Números Enteros (整数)

应用：主要用于凑整计算（凑成10, 100等）。
Calculo mental (巧算):
25 × 13 × 4
= (25 × 4) × 13   ← Conmutativa y Asociativa
= 100 × 13 = 1300

B. Decimales (小数)

应用：使小数点后的数字相加减能凑成整数。
4.8 + 3.6 + 5.2
= (4.8 + 5.2) + 3.6   ← Conmutativa
= 10 + 3.6 = 13.6

C. Fracciones (分数)

应用：主要用于分配律约分，或者结合同分母分数。
Uso de Distributiva (分配律应用):
12 × (1/3 + 1/4)
= 12 × 1/3 + 12 × 1/4
= 4 + 3 = 7
